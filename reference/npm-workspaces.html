npm workspaces 速查

核心模型

workspace 是同一个仓库中的一个独立 npm package。根 package 通过 workspaces 字段登记它们；npm 安装依赖时可以统一处理整个仓库。

概念边界：monorepo 是“一个仓库放多个项目”的组织策略；workspaces 是 npm、pnpm 或 Yarn 管理这些子 package 的能力。二者经常一起出现，但不是同义词。

{
  "private": true,
  "workspaces": ["packages/*", "apps/*"]
}

常用命令

# 在指定 workspace 执行脚本
npm --workspace server run dev

# 在所有 workspace 执行脚本
npm run test --workspaces

# 给指定 workspace 安装依赖
npm install lodash --workspace server

# 查看 workspace 列表
npm query .workspace
